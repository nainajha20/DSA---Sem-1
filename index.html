Time and space complexity

O(n)
Time complexity

Each token is scanned once. Every operator is pushed onto the stack once and popped at most once, so the total work grows linearly with the input length.

O(n)
Space complexity

In the worst case, the operator stack and postfix output can each store a number of tokens proportional to the input length.

Here, n represents the number of tokens in the expression.

Algorithm

  1. Scan the infix expression from left to right.
  2. Append operands directly to the postfix output.
  3. Push any opening bracket (, [, or { onto the stack.
  4. For a closing bracket ), ], or }, pop operators to the output until its matching opening bracket is found, then discard the opening bracket.
  5. For an operator, pop higher-precedence operators and equal-precedence left-associative operators, then push the current operator.
  6. At the end, pop all remaining operators to the output.
